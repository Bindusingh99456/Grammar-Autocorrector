How It Works

An explanation of the 8-step Natural Language Processing pipeline developed for this project, combining deterministic linguistic rules with sequence-to-sequence model correction.

The 8-Step Processing Pipeline

The system processes input sentences sequentially through eight discrete NLP stages to detect and fix grammatical errors:

1. Input Text

User supplies English text via the form or REST API up to a maximum of 2,000 characters.

2. Preprocessing

Regex collapses redundant whitespace and normalizes formatting while preserving sentence punctuation.

3. Tokenization

NLTK tokenizers segment text into sentences and track exact character offsets for each word and punctuation symbol.

4. POS Tagging

NLTK's Averaged Perceptron Tagger assigns Penn Treebank tags (PRP, VB, VBZ, VBP, DT, NN) to analyze syntactic roles.

5. Contextual Analysis

Examines subject-verb pairs, auxiliary verbs, article noun pairs, and phonetic vowel sounds of subsequent tokens.

6. Error Detection

Identifies agreement mismatches (e.g. "he eat", "she are", "a engineer") while shielding quoted text and proper nouns.

7. Correction

Morphological inflection engine updates verbs and articles; fine-tuned FLAN-T5 handles broader phrasing when confident.

8. Corrected Output

Assembles the corrected sentence, constructs inline diff highlights (<del> and <ins>), and itemizes all edits.

Worked Example

Here is a complete trace of how my pipeline processes a test sentence from my course report:

Step 1: Input text
"She go to college every day."
Step 2: Preprocessing
Regex normalizes whitespace: "She go to college every day."
Step 3: Tokenization
Tokens: ['She', 'go', 'to', 'college', 'every', 'day', '.']
Step 4: POS Tagging
[('She', 'PRP'), ('go', 'VBP'), ('to', 'TO'), ('college', 'NN'), ('every', 'DT'), ('day', 'NN'), ('.', '.')]
Step 5: Contextual Analysis
Subject 'She' (PRP, 3rd-person singular) is followed by verb 'go' (VBP, non-3rd person present).
Step 6: Error Detection
Rule violation detected: 3rd-person singular pronoun requires a 3rd-person singular verb form (VBZ).
Step 7: Correction
Verb inflection: 'go' ends in 'o', applying rule to inflect as 'goes'. Span: [4, 6].
Step 8: Corrected Output
"She goes to college every day." (1 edit applied: "go" → "goes" via subject_verb_agreement)
